# LayerForge website
A standalone responsive HTML/CSS/JS website for a custom 3D-printing business.

Files:
- index.html — website
- style.css — styling
- script.js — estimator, quote form feedback and demo order tracking

Open index.html in a browser to preview it.

Important:
The quote form and tracking are front-end demos. To receive real orders, connect the form to a backend/email service or your ecommerce platform.
